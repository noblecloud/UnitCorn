# 0.9.1

**UnitCorn is now LGPLv3.** Everything published up to unitcorn 0.9.0 and
WeatherUnits 0.8.0 stays MIT.

## License

- **`LGPL-3.0-only`.** `LICENSE.txt` carries the LGPLv3, `COPYING.txt` the GPLv3
  it refers to, and `LICENSE-MIT-HISTORIC.txt` keeps the MIT text for the
  releases published before this switch. Changes to UnitCorn itself stay under
  the LGPLv3; using it from software under any license is unaffected.
- **The WeatherUnits shim carries the same license.** It ships in the same
  release run, so `LICENSE.txt` and `COPYING.txt` are listed in its
  `license-files` and embedded in both its wheel and its sdist.

## Housekeeping

- The name is written **UnitCorn** wherever a title case is appropriate:
  headings and prose. Distribution names, imports, module paths, commands and
  environment variables stay lowercase (`unitcorn`).
